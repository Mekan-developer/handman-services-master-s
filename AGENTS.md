# AGENTS

This project keeps a single set of agent instructions in **[CLAUDE.md](./CLAUDE.md)** — read that file.

It holds the Laravel Boost guidelines (framework versions, Artisan/Boost tooling, PHP and Inertia conventions) plus this project's own architecture rules: thin controllers, repository pattern, Actions/Services, Form Requests, API Resources, enums instead of raw strings, the `WithNotification` flash flow, and the tk/ru localization requirement.

Project overview, domain model, setup and API reference: **[README.md](./README.md)**.
